# Decisions

The current rule set for HitList: each entry says what holds now, why, and where it came from. When one changes,
rewrite its entry in place and add one `Updated in place <date>: …` line (the history is git); never add a new entry
beside a dead one. A new decision takes the next free number. `*default*` = the simplest reversible default, taken
while waiting for Michael; `*open*` = still a question.

Gathered on 2026-10-25 from the three specs' decision tables (IDs kept; none collided). The specs now point here.
