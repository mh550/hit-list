# Photos persist and display — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
> Tonight's runbook (`OVERNIGHT.md`) fixes the execution method: **executing-plans, inline**.

**Goal:** Every photo taken or imported is copied into the app's document directory, stored by
relative path, and shown: a thumbnail in the Spots list and a gallery on the spot detail screen.

**Architecture:** One module (`src/utils/photo-storage.ts`) is the only importer of
`expo-file-system`; it copies a cache URI to `photos/<spotId>/<mediaId>.jpg` under
`Paths.document` and resolves stored paths back to URIs at display time. A zustand media store
(`mediaBySpot`) is hydrated at launch from a new `getAllMedia` query and updated by the two review
screens, so the list and the detail screen read photos without extra DB queries.

**Tech Stack:** expo-file-system 57 (`File` / `Directory` / `Paths` API), expo-image, zustand 5,
Jest 29 + jest-expo, the `node:sqlite` harness from M3.

**Spec:** `docs/specs/2026-10-13-overnight-design.md` — D3 and §2.2 "M4 — Photos"; bugs §1.4 #1–#2.

## Global Constraints

- D3: copy into `Paths.document/photos/<spotId>/<mediaId>.jpg`; store the **relative** path
  (`photos/<spotId>/<mediaId>.jpg`) in `media.file_path`; resolve at display time; never write to
  the camera roll; never delete files tonight (soft delete leaves them).
- `photo-storage.ts` is the only production importer of `expo-file-system`.
- The jest fake mirrors the real API, copied from

  `{ intermediates?, overwrite?, idempotent? }`; `exists` is a property; `uri` is a string;
  `new File(...uris: (string | File | Directory)[])` joins its parts.
- No dependency changes (expo-file-system is already installed).
- Gates per task: `npx jest --ci`, `npm run typecheck`, `npm run lint` = 0, zero `console.error`;
  milestone gate adds `npx expo export --platform ios`.

## Review Focus

1. **The copy fails** (cache file already purged, disk full) → the spot must still save, with the
   media row pointing at the original URI rather than at a file that does not exist; no crash.
   (Task 1 `persistPhoto` falls back; Task 3 screen test.)
2. **Rows written before this change** hold absolute `file://` cache URIs → they must still
   display (passthrough), not be glued onto the document directory. (Task 1.)
3. **A spot whose `primary_photo_id` names no media row** (or is unset) → list shows its first
   photo; detail shows all photos with the first as hero; no broken image. (Task 4.)
4. **Many photos on one spot** (20 is the spec max) → the detail gallery shows every one in
   capture order; the list shows one thumbnail. (Task 4.)
5. **iOS changes the app container path on reinstall/update** → only relative paths are stored, so
   resolution always uses the current `Paths.document`. (Task 1, resolve test with a different
   document URI.)

```ts
// __mocks__/expo-file-system.ts — in-memory fake; API copied from expo-file-system 57 .d.ts files
type Part = string | FakeFile | FakeDirectory;
let documentUri = 'file:///data/Documents/';
const files = new Set<string>();
const dirs = new Set<string>();
let nextCopyError: Error | null = null;

function join(parts: Part[], dir: boolean): string {
  const raw = parts.map((p) => (typeof p === 'string' ? p : p.uri)).join('/');
  const [, scheme = '', rest = raw] = raw.match(/^([a-z][a-z0-9+.-]*:\/\/)(.*)$/i) ?? [];
  const path = rest.replace(/\/{2,}/g, '/').replace(/\/$/, '');
  return `${scheme}${scheme ? (path.startsWith('/') ? '' : '/') : ''}${path}${dir ? '/' : ''}`;
}

class FakeDirectory {
  readonly uri: string;
  constructor(...uris: Part[]) { this.uri = join(uris, true); }
  get exists(): boolean { return dirs.has(this.uri); }
  create(options?: { intermediates?: boolean; overwrite?: boolean; idempotent?: boolean }): void {
    if (this.exists && !options?.idempotent) throw new Error(`Directory ${this.uri} already exists`);
    const parent = this.uri.replace(/[^/]+\/$/, '');
    if (!options?.intermediates && !dirs.has(parent) && parent !== documentUri) {
      throw new Error(`Parent of ${this.uri} does not exist`);
    }
    dirs.add(this.uri);
  }
  get name(): string { return this.uri.replace(/\/$/, '').split('/').pop() ?? ''; }
}

class FakeFile {
  readonly uri: string;
  constructor(...uris: Part[]) { this.uri = join(uris, false); }
  get exists(): boolean { return files.has(this.uri); }
  get name(): string { return this.uri.split('/').pop() ?? ''; }
  get parentDirectory(): FakeDirectory { return new FakeDirectory(this.uri.replace(/[^/]+$/, '')); }
  async copy(destination: FakeFile | FakeDirectory, _options?: { overwrite?: boolean }): Promise<void> {
    if (nextCopyError) { const e = nextCopyError; nextCopyError = null; throw e; }
    if (!this.exists) throw new Error(`File ${this.uri} does not exist`);
    const target = destination instanceof FakeDirectory ? new FakeFile(destination, this.name) : destination;
    if (!dirs.has(target.parentDirectory.uri) && target.parentDirectory.uri !== documentUri) {
      throw new Error(`Destination directory for ${target.uri} does not exist`);
    }
    files.add(target.uri);
  }
}

export const Paths = { get document(): FakeDirectory { return new FakeDirectory(documentUri); } };
export { FakeFile as File, FakeDirectory as Directory };

export function __resetFs(doc = 'file:///data/Documents/'): void {
  documentUri = doc; files.clear(); dirs.clear(); nextCopyError = null;
}
export function __putFile(uri: string): void { files.add(uri); }
export function __fileExists(uri: string): boolean { return files.has(uri); }
export function __failNextCopy(err: Error): void { nextCopyError = err; }
```

```ts
import { Directory, File, Paths } from 'expo-file-system';

const PHOTOS_DIR = 'photos';
const HAS_SCHEME = /^[a-z][a-z0-9+.-]*:/i;

export function photoRelativePath(spotId: string, mediaId: string): string {
  return `${PHOTOS_DIR}/${spotId}/${mediaId}.jpg`;
}

/** Copies a (purgeable) cache URI into app storage; returns the path to store in media.file_path. */
export async function persistPhoto(sourceUri: string, spotId: string, mediaId: string): Promise<string> {
  try {
    new Directory(Paths.document, PHOTOS_DIR, spotId).create({ intermediates: true, idempotent: true });
    await new File(sourceUri).copy(new File(Paths.document, photoRelativePath(spotId, mediaId)));
    return photoRelativePath(spotId, mediaId);
  } catch (err) {
    console.warn('[persistPhoto] copy failed, keeping the original URI:', err);
    return sourceUri;
  }
}

/** Stored relative paths resolve against the current document dir (iOS moves it on reinstall). */
export function resolvePhotoUri(filePath: string): string {
  if (HAS_SCHEME.test(filePath) || filePath.startsWith('/')) return filePath;
  return new File(Paths.document, filePath).uri;
}
```

```ts
import { create } from 'zustand';
import type { Media } from '@/src/types';

interface MediaState {
  mediaBySpot: Record<string, Media[]>;
  setAll: (media: Media[]) => void;
  add: (media: Media) => void;
  remove: (id: string) => void;
}

export const useMediaStore = create<MediaState>((set) => ({
  mediaBySpot: {},
  setAll: (media) =>
    set({
      mediaBySpot: media.reduce<Record<string, Media[]>>((acc, m) => {
        (acc[m.spot_id] ??= []).push(m);
        return acc;
      }, {}),
    }),
  add: (m) =>
    set((s) => ({
      mediaBySpot: {
        ...s.mediaBySpot,
        [m.spot_id]: [...(s.mediaBySpot[m.spot_id] ?? []), m].sort((a, b) =>
          a.created_at.localeCompare(b.created_at),
        ),
      },
    })),
  remove: (id) =>
    set((s) => ({
      mediaBySpot: Object.fromEntries(
        Object.entries(s.mediaBySpot).map(([k, list]) => [k, list.filter((m) => m.id !== id)]),
      ),
    })),
}));
```
