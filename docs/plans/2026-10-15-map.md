# Map view with a Map | List toggle — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
> Tonight's runbook (`OVERNIGHT.md`) fixes the execution method: **executing-plans, inline**.

**Goal:** The Spots tab gets a Map | List switch; Map shows every filtered spot as an Apple Maps pin
(drafts in a different colour) and tapping a pin's callout opens the spot.

**Architecture:** `src/components/SpotMap.tsx` renders `react-native-maps` `MapView` + one `Marker`
per spot; its starting region comes from a pure helper (`src/utils/map-region.ts`). The Spots screen
keeps one layout for both modes: a segmented control at the top of the screen, then the map or the
list, with the FAB and the filter button unchanged. `viewMode` lives on the spots store.

**Tech Stack:** react-native-maps 1.27.2 (Expo SDK 57 pin, Apple Maps in Expo Go, no API key),
zustand 5, Jest 29 + jest-expo with a manual mock.

**Spec:** `docs/specs/2026-10-13-overnight-design.md` — D2, D8 (no clustering tonight), §2.2 "M5 — Map".

## Global Constraints

- D2: `react-native-maps` with the default provider (Apple Maps on iOS). No Google provider, no key.
- D8: pins only; spots at one location overlap. Clustering is stretch S1.

  `testID`, `children`); named `Marker` (props used: `identifier`, `coordinate: LatLng`, `title`,
  `description`, `pinColor`, `onCalloutPress`); `Region = LatLng & { latitudeDelta, longitudeDelta }`.
- Production code never imports test factories: the Seattle fallback is a constant in
  `src/constants/map.ts` (same coordinates as `createTestSpot`: 47.6062, −122.3321).
- Gates per task: jest, typecheck, lint = 0, zero `console.error`; milestone adds `expo export --platform ios`.

## Review Focus

1. **No spots and no location yet** (first launch, permission denied) → the map still opens on a
   sensible region (Seattle default), no crash, the FAB still works. (Task 1 region test; Task 2.)
2. **All spots at exactly one point** (several features at one location, D8) → the bounding box has
   zero size; the map must still zoom to a usable level, not to an infinitely small span. (Task 1.)
3. **Spots on both sides of the antimeridian or very far apart** (a trip) → the region must contain
   all of them (plain min/max is fine at personal scale; it must not produce a negative delta). (Task 1.)
4. **Filters active in Map mode** → the map shows exactly the filtered spots, same as the list. (Task 2.)
5. **Switching modes keeps the choice** while the app runs (store, not component state), and the
   default is List so the existing flow is unchanged. (Task 2.)

```ts
// src/constants/map.ts
import type { Region } from 'react-native-maps';
export const DEFAULT_REGION: Region = { latitude: 47.6062, longitude: -122.3321, latitudeDelta: 0.1, longitudeDelta: 0.1 };
export const MIN_DELTA = 0.01;            // ≈ 1 km: never zoom tighter than a few blocks
export const CURRENT_LOCATION_DELTA = 0.05;
```

```ts
// src/utils/map-region.ts
export function initialRegion(spots: Spot[], current: GeoPoint | null): Region {
  if (current) return { ...current, latitudeDelta: CURRENT_LOCATION_DELTA, longitudeDelta: CURRENT_LOCATION_DELTA };
  if (spots.length === 0) return DEFAULT_REGION;
  const lats = spots.map((s) => s.location.latitude);
  const lngs = spots.map((s) => s.location.longitude);
  const [minLat, maxLat, minLng, maxLng] = [Math.min(...lats), Math.max(...lats), Math.min(...lngs), Math.max(...lngs)];
  return {
    latitude: (minLat + maxLat) / 2,
    longitude: (minLng + maxLng) / 2,
    latitudeDelta: Math.max((maxLat - minLat) * 1.4, MIN_DELTA),
    longitudeDelta: Math.max((maxLng - minLng) * 1.4, MIN_DELTA),
  };
}
```

```tsx
// src/components/SpotMap.tsx
export const DRAFT_PIN = palette.yellow[500];
export const SPOT_PIN = palette.blue[500];

export function SpotMap({ spots, currentLocation, onOpenSpot }: Props) {
  // initialRegion only: the map owns its camera after mount, so it does not jump on every filter change.
  const [region] = useState(() => initialRegion(spots, currentLocation));
  return (
    <MapView style={StyleSheet.absoluteFill} initialRegion={region} showsUserLocation>
      {spots.map((spot) => (
        <Marker
          key={spot.id}
          identifier={spot.id}
          testID={`spot-marker-${spot.id}`}
          coordinate={spot.location}
          title={getSpotDisplayName(spot)}
          description={spot.status === SpotStatus.Draft ? 'Draft' : spot.feature.type?.replace(/_/g, ' ')}
          pinColor={spot.status === SpotStatus.Draft ? DRAFT_PIN : SPOT_PIN}
          onCalloutPress={() => onOpenSpot(spot.id)}
        />
      ))}
    </MapView>
  );
}
```
