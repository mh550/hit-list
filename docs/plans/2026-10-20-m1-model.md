## Migration 3

`src/db/schema.ts`: append `migration3`; `MIGRATIONS = [migration1, migration2, migration3]`. 1 and 2 untouched
(diff = additions only). Runs inside `migrateDb`'s per-migration transaction with foreign keys OFF.

**Step 1 — add columns**

```sql
ALTER TABLE spots ADD COLUMN feature_types_json TEXT NOT NULL DEFAULT '[]';
ALTER TABLE spots ADD COLUMN stopped INTEGER NOT NULL DEFAULT 0;
ALTER TABLE spots ADD COLUMN natural_speed INTEGER;
ALTER TABLE spots ADD COLUMN notes TEXT;
ALTER TABLE spots ADD COLUMN legacy_json TEXT;
```

**Step 2 — JS backfill**, every row incl. soft-deleted:
`SELECT id, feature_json, in_run_json, landing_json, metadata_json FROM spots` (status not read: nothing uses it),
then per row one `UPDATE spots SET feature_types_json = ?, stopped = ?, natural_speed = ?, notes = ?, legacy_json = ? WHERE id = ?`.
Pure helper `migrateSpotRowV3(row)` → `{ feature_types_json, stopped, natural_speed, notes, legacy_json }`, exported
for unit tests.

- `parse(text)`: `JSON.parse`; non-object or throws → `{}` and the raw text goes to `legacy.raw_<feature|in_run|landing|metadata>` (column name without `_json`, as built).
  Migration never throws on row data (a throw would leave the DB at v2 with a v3 mapper = no spots on the phone).
- `feature_types` = `[feature.type]` if `type` is one of the eight kept values, else `[]` (`'other'`, unknown → `[]`).
- `stopped` = `feature.skate_stops?.is_stopped === true ? 1 : 0`.
- `natural_speed` = `in_run.natural_speed - 1` if it is an integer 1–5, else NULL.
- `notes` = `metadata.notes` if a string with non-whitespace, else NULL (stored as typed, not trimmed).
- `legacy` = Legacy keys below; `legacy_json` = `JSON.stringify(legacy)` or NULL when no key survived.

**Step 3 — rebuild without the old columns** (SQLite's create-copy-drop-rename; FK off ⇒ no media cascade):

```sql
CREATE TABLE spots_new (
  id TEXT PRIMARY KEY NOT NULL,
  name TEXT,
  generated_name TEXT,
  latitude REAL NOT NULL,
  longitude REAL NOT NULL,
  created_at TEXT NOT NULL DEFAULT (datetime('now')),
  updated_at TEXT NOT NULL DEFAULT (datetime('now')),
  deleted_at TEXT,
  feature_types_json TEXT NOT NULL DEFAULT '[]',
  stopped INTEGER NOT NULL DEFAULT 0,
  natural_speed INTEGER,
  notes TEXT,
  legacy_json TEXT,
  primary_photo_id TEXT
);
INSERT INTO spots_new (id, name, generated_name, latitude, longitude, created_at, updated_at, deleted_at,
                       feature_types_json, stopped, natural_speed, notes, legacy_json, primary_photo_id)
  SELECT id, name, generated_name, latitude, longitude, created_at, updated_at, deleted_at,
         feature_types_json, stopped, natural_speed, notes, legacy_json, primary_photo_id FROM spots;
DROP TABLE spots;                       -- also drops idx_spots_status and idx_spots_deleted_at
ALTER TABLE spots_new RENAME TO spots;
CREATE INDEX IF NOT EXISTS idx_spots_deleted_at ON spots(deleted_at);
```

Gone: `status`, `feature_json`, `in_run_json`, `landing_json`, `metadata_json`, `idx_spots_status`. Media untouched.

**Mappers (`src/db/spots.ts`, M1-02)**: `SpotRow` = the v3 columns minus `legacy_json`;
`const SPOT_COLUMNS = 'id, name, generated_name, latitude, longitude, created_at, updated_at, deleted_at, feature_types_json, stopped, natural_speed, notes, primary_photo_id'`
used by `getSpot`/`getSpots` (no `SELECT *`). `rowToSpot`: `feature_types = JSON.parse(feature_types_json)`,
`stopped = row.stopped === 1`, `natural_speed = row.natural_speed === null ? undefined : row.natural_speed`
(never `||`/`??` on a value that can be 0), `notes = row.notes ?? undefined`. `insertSpot` writes the four.
`updateSpot`: `feature_types` when defined, `stopped` when `!== undefined` (0/1), `natural_speed` / `notes`
when `!== undefined` (null → NULL). New `getSpotLegacy(db, id): Promise<SpotLegacy | null>`
(`SELECT legacy_json FROM spots WHERE id = ?`, parse or null), re-exported from `src/db/index.ts`.
`spots-store.applySpotUpdate`: `notes: null` / `natural_speed: null` → `undefined`, 0 kept.

**Settings (M1-03)**: no SQL. `getUserSettings` builds `{ units, batch_import_radius }` from the parsed blob over
the defaults (an old `gear` key is dropped on read, not spread through); `saveUserSettings` writes the two keys.

## Legacy keys

The 16 keys of spec §4 item 2, flat, in this order; lengths stay metres (unit applied at read time, M3):

| key | from |
|---|---|
| `custom_type` | `feature.custom_type` (only `'other'` ever wrote it) |
| `shape` | `feature.shape` |
| `length_m` / `height_m` / `width_m` | `feature.dimensions.length` / `.height` / `.width` |
| `material` | `feature.material` |
| `stop_type` | `feature.skate_stops.stop_type` |
| `stop_description` | `feature.skate_stops.stop_description` |
| `removable` | `feature.skate_stops.removable` |
| `difficulty` | `feature.difficulty` |
| `setup_options` | `in_run.setup_options`, whole, as stored (gear + build, D22) |
| `landing_difficulty` | `landing.difficulty` |
| `landing_surface` | `landing.surface` |
| `intensity` / `bustability` / `bustability_notes` | `metadata.*` |

Counts as empty, never archived: missing/null, **empty string** (and whitespace-only), **empty array**,
non-finite numbers, **`is_stopped: false`** (is_stopped is never archived: it became `stopped`),
`removable: false` (edit wrote it by default whenever stops were on: noise, like status). **`status` is never
archived** (every row has one). Plus the four `raw_<column>` keys only for unparseable JSON (above).
`legacy_json` NULL when nothing remains (the common case).

## Two-step type change

- **M1-02** adds `NaturalSpeed`, `SpotLegacy`, `Spot.feature_types/stopped/natural_speed?/notes?`, nullable
  `notes`/`natural_speed` in `SpotUpdate`; **keeps** `status/feature/in_run/landing/metadata` on `Spot` so screens
  compile. `rowToSpot` returns them as fixed empty defaults (`status: Complete`, `feature: {}`,
  `in_run: { setup_options: [] }`, `landing: {}`, `metadata: {}`); `insertSpot`/`updateSpot` ignore them (their
  columns are gone). Factory gets `feature_types: []`, `stopped: false` and `status: Complete` so DB round trips
  stay `toEqual`. Interim: old edit fields save nowhere and the detail shows none; fine, no merge before M1 ends.
- **M1-03** removes gear (`GearItem`, `BuildItem`, `UserSettings.gear`, store/actions/profile/FilterSheet gear),
  `SpotStatus` + `Spot.status` (badge, pin, Show Drafts, "Save as Draft" → "Save", review screens write
  `feature_types: []`, `stopped: false`), `SortField.Intensity`, `Requirement`/`SetupOption`/`RequirementCategory`,
  and `SpotFilters` → final shape; store gets the `stopped` filter.
- **M1-04** removes the nested model (`feature/in_run/landing/metadata`, `FeatureDetails` …, `Material`,
  `StopType`, `LandingSurface`, `FeatureType.Other`), deletes `StarRating`/`RatingBadge`, adds
  `FEATURE_TYPE_LABELS` + `featureTypesLabel`, strips edit to photos + name + delete and detail to photos + title
  + notes; type filter any-of on `feature_types`, speed range on 0–4. Map callout = `featureTypesLabel(spot)`
  until M5 joins all types with " · ".
