On the phone

On the desktop, run npm run start:tailscale in the project folder. Then scan the QR code with the iPhone camera, and it opens in Expo Go. The full guide is docs/RUNNING-ON-PHONE.md.

A few things can only be checked on a real phone:

  1. The sort chips under the search field are one short row, not half the screen.
  2. Two spots at the same place show a blue circle marked 2. Tapping it lists both by name.
  3. Tapping a pin's bubble opens that spot.
  4. In Edit, the photo row fits, and the × on each thumbnail is easy to hit.
  5. Declining the camera shows Close and Open Settings.
